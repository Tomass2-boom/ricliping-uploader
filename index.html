Ricliping Uploader

A personal desktop tool for sending your own finished videos to your own TikTok drafts.

What it does

Ricliping Uploader is a small desktop application used by a single independent video creator to move finished video files from their own computer into their own TikTok account's drafts folder.

Editing is done elsewhere. This tool exists only for the last step: moving the finished file across, so it does not have to be transferred to a phone and uploaded by hand each time.

How it works

  1. You sign in with TikTok. TikTok's own login screen handles this — the tool never sees your password.
